# 《极速外卖》可玩 Demo

浏览器直接打开 [`index.html`](./index.html) 即可试用（无需安装、无需构建）。

## 对应 PRD / MVP

| 能力 | Demo 情况 |
|------|-----------|
| 大学城地图 | 有（食堂/宿舍/教学楼/校门/喷泉） |
| 抢单→取货→送达 | 有 |
| 3 载具换车 | 单车 / 电动 / 摩托 |
| 2 名 AI 对手 | 小红、阿强 |
| 加速 / 倒油 / 诱饵 | 有（局内购倒油或诱饵） |
| 三步新手引导 | 有（可跳过，会记住） |
| 虚拟摇杆 | 有 |
| 结算 + 激励视频×2 | 有（模拟，不影响名次） |
| 好友联机 | 无（下阶段） |

## 操作

- **移动：** WASD / 方向键 / 左下角摇杆  
- **抢单：** 点击地图上橙色分数气泡  
- **换车：** 靠近蓝色「换」站，点「换车」或按 `F`  
- **技能：** 右下角技能键或 `E`；长按技能键切换已拥有技能  

## 建议试玩路径

1. 选「快速体验（90秒）」  
2. 跟引导完成第一单  
3. 赚金币后买倒油或换电动车  
4. 抢一次天价单，体验与 AI 竞争
