# 极速外卖（Express Delivery）

抖音小游戏《极速外卖》产品与可玩 Demo 仓库。

玩家扮演外卖员，在大学城地图内完成 **抢单 → 取货 → 送达**，可换载具、使用技能与 AI 竞技，单局约数分钟。

## 可玩 Demo

本地用浏览器打开 [`demo/index.html`](demo/index.html)。

局域网分享可运行：

```bat
demo\start-lan.bat
```

## 当前 Demo 能力（对齐 MVP）

- 大学城地图、三载具换车
- 抢单 / 取货 / 送达、天价单播报
- 加速 / 倒油 / 假单诱饵
- 2 名 AI 对手、新手引导、虚拟摇杆
- 结算与激励视频×2（模拟）

好友联机房尚未接入，见 PRD 后续版本。
