# 《极速外卖》界面信息架构（IA）与 HUD

## 1. 页面层级

```text
启动闪屏
 └─ 大厅 Lobby
     ├─ 单机挑战
     ├─ 好友房
     │   ├─ 房间等待 Room
     │   └─ 对局 InGame
     │       └─ 结算 Result
     ├─ 设置（音效/震动）
     └─（P1）段位 / 商店 / 任务
```

---

## 2. 大厅 Lobby

**一屏只做一件事：选模式开玩。**

| 元素 | 说明 |
|------|------|
| 品牌标题 | 「极速外卖」主视觉，偏大 |
| 主 CTA | 「好友一起送」→ 创建/加入房间 |
| 次 CTA | 「单机加班」→ 挑战关 |
| 弱入口 | 设置 |

**不做（MVP）：** 复杂活动 Banner、多 Tab 仪表盘、首屏统计条。

---

## 3. 房间等待 Room

| 元素 | 说明 |
|------|------|
| 房间号 | 可复制 |
| 座位列表 | 2–4 槽，显示头像昵称 |
| 地图预览 | 大学城缩略 |
| 规则一行 | 「180 秒 · 抢单送达 · 可换车」 |
| 房主按钮 | 「开始配送」 |
| 成员状态 | 准备中（MVP 可省略准备，房主直接开） |

## 4. 局内 HUD（InGame）

### 4.1 布局分区

```text
┌─────────────────────────────────────────┐
│ [倒计时]          [排名条 1~4 简分]      │  顶栏
│ [当前订单卡：取货/送达箭头+剩余时限]      │  顶栏下
├─────────────────────────────────────────┤
│                                         │
│              游戏世界（全出血）            │
│                                         │
├─────────────────────────────────────────┤
│ [摇杆]                    [技能键] [互动] │  底栏
└─────────────────────────────────────────┘
```

### 4.2 组件规格

| 组件 | 内容 | 备注 |
|------|------|------|
| 倒计时 | mm:ss，最后 30s 变强调色 | 不可被技能完全遮挡 |
| 排名条 | 最多 4 人：名次色点 + 简称 + 分数 | 自己高亮 |
| 订单卡 | 状态文案（去取货/去送达）+ 时限环 + 目标方向箭头 | 无单时显示「点击气泡抢单」 |
| 摇杆 | 左下，半透明 | 左手区 |
| 技能键 | 右下大键，CD 遮罩 | 长按无效，单击释放 |
| 互动键 | 靠近换车站/取送点时高亮「换车/取货/送达」 | 可与自动触发并存；MVP 取送自动，换车需按或靠近菜单 |
| Toast | 顶部中央短讯 | 「被抢」「天价单」「保护中」 |
| 播报条 | 高价单刷新时顶部横幅 2s | |

### 4.3 世界内 UI

- 订单气泡：分数数字 + 简易图标，可点击抢  
- 取货点/顾客点：地面圈 + 简单图标  
- 换车站：醒目标牌  
- 技能预警：倒油落点圈（对方可见）  

### 4.4 简便性原则

- 同时需要阅读的规则信息 ≤3 块（倒计时、订单卡、技能键）  
- 不在局内打开多级菜单；换车用车站处 1 层列表

## 5. 换车面板（车站浮层）

```text
┌ 换车站 ──────────────┐
│ 共享单车（当前） 免费  │
│ 电动车  80 币 [租用]  │  ← 未完成 1 单则灰显
│ 摩托车 150 币 [租用]  │
│          [关闭]       │
└──────────────────────┘
```

选中后读条 1.5s，可取消（松手/离开范围）。

---

## 6. 结算 Result

| 区域 | 内容 |
|------|------|
| 名次大字 | 第 N 名 |
| 数据行 | 得分 / 完成单数 / 使用技能次数 |
| 高光标签 | 最多 1 个（如「抢单王」） |
| 主 CTA | 「再来一局」 |
| 广告 CTA | 「看视频，本局奖励展示 ×2」（不影响名次） |
| 次 CTA | 「回大厅」 |

**禁止：** 结算页堆叠商城、任务、复杂分享多步（投稿为 P2）。

---

## 7. 新手引导遮罩

三步，可跳过：

1. 「点气泡，抢一单」  
2. 「去餐厅取货」  
3. 「送到顾客手上」  

每步只高亮一个目标，其余压暗。

## 8. 关键线框优先级（交付美术前）

1. 局内 HUD（最影响操作）  
2. 结算  
3. 大厅 + 房间  
4. 换车浮层  
5. 引导遮罩
