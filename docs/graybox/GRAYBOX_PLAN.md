# 《极速外卖》灰盒验证方案

## 1. 目的

在正式美术与完整联机之前，用最低成本验证四段核心爽感是否成立：

| 序号 | 爽感段 | 成功标准（主观+客观） |
|------|--------|----------------------|
| A | 抢单 | 受试者主动去抢高分单；出现「被抢」情绪但不弃游 |
| B | 送达 | 首次完成一单 ≤40s；感到时间压力但可控 |
| C | 换车 | ≥70% 受试者能说出车差异，且出现主动绕路换车 |
| D | 干扰 | 「想再坑」与「被恶心」平衡；恶心问卷 ＜25% |

**门禁：** A–D 全部达标，才允许排期迈巴赫 / 多地图 / 段位等扩容。

---

## 2. 灰盒范围

### 包含

- 俯视角矩形街区（色块建筑 + 道路）  
- 玩家移动（键盘/摇杆逻辑）  
- 订单气泡、抢单、取货、送达、计分、180s 倒计时  
- 3 种载具 + 换车站  
- 加速 / 倒油（可先对 AI）/ 诱饵（可后置）  
- 1–2 个简单 AI 抢单员  
- 结算与「再来一局」  

### 不包含

- 精美美术、音效包装、抖音登录、真实好友房网络（可用本地双角色或 AI 代替首轮）  
- 迈巴赫、匹配、广告 SDK  

本地可玩原型路径：[`../../graybox/index.html`](../../graybox/index.html)（浏览器直接打开）。

---

## 3. 验证流程（建议 1–2 天）

1. **内部自测**（程序+策划）：跑通流程，修阻断 Bug。  
2. **5–8 人小样本**（目标用户近似）：不讲解规则，只说「这是送外卖小游戏」。  
3. **记录指标：** 首次完成一单耗时、单局完成单数、是否换车、技能使用次数、再来一局是否点击。  
4. **问卷 4 题：**  
   - 规则是否好懂？（1–5）  
   - 换车有没有用？（1–5）  
   - 是否觉得被恶心？（是/否）  
   - 还想不想再玩一局？（是/否）  
5. **复盘调参：** 按 [NUMBERS.md](../specs/NUMBERS.md) §9 旋钮表调整，再测一轮。

## 4. 版本门禁对照

| 灰盒版本 | 必须证明 | 失败则 |
|----------|----------|--------|
| GB-A | 抢单+送达爽 | 砍复杂订单，缩地图 |
| GB-B | 换车改变决策 | 加大速度差或降租金 |
| GB-C | 干扰公平好玩 | 加 CD/降时长/加强保护 |
| GB-Go | 再来一局 ≥45% | 不加内容，继续打磨核心 |
