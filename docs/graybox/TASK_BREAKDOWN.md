# 灰盒任务拆分（程序 / 美术 / 服务端）

预估总人力：**约 5–8 人日**（灰盒级，非生产质量）。

---

## 程序（Client）约 3–4 人日

| ID | 任务 | 预估 | 依赖 | 完成定义 |
|----|------|------|------|----------|
| C1 | 场景：道路碰撞、出生点、车站、商家/顾客点 | 0.5d | — | 角色可在路上移动不穿模 |
| C2 | 输入：键盘 WASD + 虚拟摇杆（可选） | 0.25d | C1 | 移动流畅 |
| C3 | 订单管理器：刷单、状态机、计分 | 0.75d | C1 | 可完成一单并加分 |
| C4 | 抢单与持单上限 | 0.25d | C3 | 持 1 单；冲突有反馈 |
| C5 | 三载具数值切换 + 换车读条 | 0.5d | C2 | 车站可换三种车 |
| C6 | 技能：加速、倒油（对 AI） | 0.5d | C2 | CD 与效果可见 |
| C7 | AI 抢单员 ×1–2 | 0.5d | C3 | AI 能完成取送 |
| C8 | HUD + 结算 + 再来一局 | 0.5d | C3 | 对局闭环 |
| C9 | 配置表接入 NUMBERS 关键字段 | 0.25d | C3–C6 | 改 JSON/常量即可调参 |

**本仓库浏览器灰盒**已覆盖 C1–C8 的可玩子集，供策划立即开测；正式 Cocos 工程可对照重写。
