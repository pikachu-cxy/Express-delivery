## 1. 场景设计总原则

本游戏地图是 **「限时竞技舞台」**，不是开放世界城市模拟。

| 原则 | 说明 |
|------|------|
| 小而密 | 电动车对角线跑图约 **8–12 秒**；空跑超过 15 秒视为设计失败 |
| 环形成熟 | 主环路保证永不迷路；近路提供博弈 |
| 主题靠美术差 | 多地图差异优先在 **氛围/地标/配色**，而不是面积 |
| 功能点够用 | 商家、顾客、换车站数量服务 4 人抢单，宁少勿散 |
| 装饰服从认路 | 每个区域 1 个地标即可 |

## 2. 地图规格（全图通用）

### 2.1 空间结构模板

```text
        [北地标]
    ┌────主环路────┐
    │  近路A   近路B │
    │ 商家簇  顾客簇 │
    │   ★换车站★    │
    └────主环路────┘
        [南地标]
```

| 元素 | 数量建议 | 说明 |
|------|----------|------|
| 出生点 | 4 | 四角或环路均分，避免开局撞车 |
| 商家（取货） | 5–7 | 成簇，不要平均撒满 |
| 顾客（送达） | 8–10 | 覆盖环路外侧与内侧 |
| 换车站 | 2 | 东西或南北对称，降低「控站」 |
| 主环路 | 1 | 双向可视宽度足够 2 车交错 |
| 近路 | 2–3 | 可被事件封锁（P1） |
| 施工/减速区 | 0–2 | MVP 可纯装饰 |

### 2.2 动线验收

- 新手闭眼沿环路骑一圈，应能经过至少 1 换车站、2 商家、3 顾客区  
- 高价值单的取送点距离：约 **中等偏长**（鼓励抢车与抢路），不要总是隔壁

## 4. MAP_CAMPUS · 大学城街区（MVP 主场景）

### 4.1 场景故事

下午四点，校园外卖高峰。共享单车刚起步，天价奶茶单在宿舍楼闪烁。谁先换上电动车，谁就能在教学楼环路封神。

### 4.2 氛围与调色

| 项 | 规定 |
|----|------|
| 时段 | 晴天午后 |
| 主色 | 草绿 + 砖红宿舍 + 浅灰道路 |
| 天空/远景 | 简洁浅蓝，不画复杂云海 |
| 噪音装饰 | 篮球场、公告栏、共享单车停车点、猫 |

### 4.3 区域划分（认路用地名）

| 区域 | 地标 | 功能倾向 |
|------|------|----------|
| 北区 · 食堂广场 | 大食堂穹顶色块 | 商家密集（取货热区） |
| 东区 · 教学楼 | 「T」形教学楼 | 顾客点（教室门外） |
| 南区 · 宿舍海 | 两栋对称宿舍 | 顾客密集（送达热区） |
| 西区 · 校门商铺 | 校门拱门 | 混合商家 + 1 换车站 |
| 中心 · 喷泉环岛 | 喷泉/雕塑 | 环路枢纽；另 1 换车站靠环岛 |

### 4.4 推荐点位配额

- 商家 6：食堂 3、西门商铺 2、咖啡厅 1  
- 顾客 9：宿舍 5、教学楼 3、体育馆 1  
- 换车站 2：环岛旁、西门旁  
- 出生点 4：环岛外四向  

### 4.5 近路设计

| 近路 | 风险/收益 |
|------|-----------|
| 食堂后门巷 | 窄，单车有优势；电动/摩托易「挤」 |
| 宿舍抄近道 | 穿草地（视觉），可设轻微减速装饰 |
| 地下通道口（装饰） | P1 可封锁制造变线 |

### 4.6 名场面潜台词（传播用）

- 宿舍楼下多人抢同一奶茶天价单  
- 教学楼门口压线送达  
- 西门换车站读条被倒油

## 5. MAP_CBD · 写字楼商圈（v1.0）

### 5.1 场景故事

午餐战。格子西装人群是背景板，外卖员在塔楼峡谷里钻。高价单常刷在「A座前台」。

### 5.2 氛围与调色

| 项 | 规定 |
|----|------|
| 时段 | 正午偏白光 |
| 主色 | 冷灰玻璃蓝 + 人行道浅米 |
| 地标 | 两栋超高色块塔楼、地铁出入口、星巴克式虚构咖啡（改名） |
| 情绪 | 整齐、压迫、效率 |

### 5.3 区域

| 区域 | 地标 | 倾向 |
|------|------|------|
| 塔楼峡谷 | 双塔 | 顾客（前台/楼下） |
| 地下商街入口 | 台阶图标 | 商家簇 |
| 城市绿地 | 小公园 | 换车站 + 缓冲 |
| 出租车泊位 | 黄线 | 出生/减速叙事 |

### 5.4 玩法差异（规则仍通用，空间手感不同）

- 道路更「直」，公路车（P1）更香  
- 近路更少，决策更偏「抢单时机」而非「钻巷」

## 6. MAP_NIGHT · 夜市小吃街（v1.0）

### 6.1 场景故事

晚上九点，灯串与油烟（卡通表示）。订单是烤串和饮料，天价单可能是「全桌加免辣」。适合迈巴赫（P2）出现制造违和名场面。

### 6.2 氛围与调色

| 项 | 规定 |
|----|------|
| 时段 | 夜晚，但画面仍要亮、可读 |
| 主色 | 深青底 + 暖黄灯串 + 红幌 |
| 禁忌 | 漆黑看不见订单；禁止恐怖气氛 |
| 地标 | 牌楼、河堤、排档连棚 |

### 6.3 区域

| 区域 | 地标 | 倾向 |
|------|------|------|
| 主街排档 | 连棚灯 | 商家极密 |
| 河堤步道 | 护栏 | 顾客散步点 |
| 停车场 | 空地 | 换车站、超载具事件点（P2） |
| 巷弄 | 窄 | 单车优势区 |

### 6.4 玩法差异

- 视觉干扰略多（灯串粒子要克制）  
- 适合「假单诱饵」在灯火里骗人  
- P1 可加小雨天气层

## 7. 场景层级（每张地图通用分层思维）

供关卡与美术对齐，不涉及引擎：

| 层 | 内容 | 注意 |
|----|------|------|
| 地面层 | 道路、草地、人行道色 | 道路对比度要够 |
| 功能层 | 取送点圈、车站、出生 | 永远清晰 |
| 建筑层 | 阻挡体块 | 剪影简单 |
| 装饰层 | 树、灯、人群剪影 | 可减；勿挡气泡 |
| 动态层 | 角色、载具、特效、订单气泡 | 最高优先级 |
| 天气层（P1） | 雨、雾轻量 | 不降可读性 |

## 8. 场景内「演出时刻」（产品节奏）

与 180 秒对局对齐的空间事件感（规则事件详见 PRD；此处是场景表现）：

| 时刻 | 场景表现意向 |
|------|----------------|
| 开局 0–10s | 出生点简短尘土/开灯；订单同时冒泡 |
| 每 ~45s | 天价单：目标点脉冲光 + 顶部播报 |
| 换车成功 | 车站小旗晃一下 |
| 倒油 | 局部地面反光卡通油膜 |
| 最后 30s | 环境光微暖或倒计时UI主导，不改地图结构 |
| 结算 | 可切到胜利者侧写漫画框（P1） |

## 9. 大厅 / 房间 / 结算「场景」

局外也算产品场景，保持同一画风：

| 场景 | 画面 |
|------|------|
| 大厅 | 大学城一角插画 + 品牌标题「极速外卖」；主按钮「好友一起送」 |
| 房间等待 | 地图缩略（大学城）+ 座位头像；不要复杂 3D 大厅 |
| 结算 | 名次大字 + 角色胜利/挫败姿势；背景可用本局地图虚化 |
