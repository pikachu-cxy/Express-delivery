# 《极速外卖》道具与物品设计

> 产品内容文档 · 不含技术实现

---

## 1. 分类总览

| 大类 | 定义 | MVP |
|------|------|-----|
| A. 载具 | 局内移动与 build | 单车 / 电动 / 摩托 |
| B. 订单与包裹 | 玩法核心对象 | 全档订单气泡 + 保温袋表现 |
| C. 主动技能道具 | 玩家释放的互害/增益 | 加速、倒油、假单诱饵 |
| D. 场景互动物 | 地图上可触发的装置 | 换车站；施工锥为装饰碰撞 |
| E. 局内增益拾取 | 短时道具箱 | **非 MVP（P1）** |
| F. 外观收藏 | 不改强度的皮肤/表情 | **非 MVP（P1）** |
| G. 超载具与特殊事件物 | 喜剧高潮 | **非 MVP（P2）** |

## 2. A. 载具道具卡

### 2.1 共享单车 `VEH_BIKE`

| 项 | 内容 |
|----|------|
| 定位 | 开局默认；窄路灵活 |
| 外观 | 共享蓝、车筐可挂小袋、略旧 |
| 获取 | 出生自带；换车站免费切回 |
| 叙事标签 | 「还能更快吗？」 |

### 2.2 电动车 `VEH_EBIKE`

| 项 | 内容 |
|----|------|
| 定位 | 均衡主力 |
| 外观 | 黑/青车身 + 背后保温箱 |
| 获取 | 完成 ≥1 单后，换车站花局内币租用 |
| 叙事标签 | 「终于像个外卖员了」 |

### 2.3 摩托车 `VEH_MOTO`

| 项 | 内容 |
|----|------|
| 定位 | 高风险高效率 |
| 外观 | 张扬涂装、夸张后视镜 |
| 获取 | 局内币购买 |
| 叙事标签 | 「风里来雨里去（雨天 P1 不稳）」 |

### 2.4 公路车 `VEH_ROAD`（P1）

直线爆发、载重低；造型瘦长竞速。

### 2.5 迈巴赫 `VEH_MAYBACH`（P2 超载具）

| 项 | 内容 |
|----|------|
| 定位 | 喜剧核武器：极快、招恨、不稳定（热度/油耗） |
| 外观 | 过长车身、镀铬、不合比例的外卖灯牌 |
| 获取 | 天价单奖励或稀有事件，**仅本局临时** |
| 禁止 | 永久付费解锁属性碾压 |

## 3. B. 订单与包裹

### 3.1 订单气泡（地图 UI 物）

| 档位 | 名称 | 视觉 | 产品语义 |
|------|------|------|----------|
| N | 普通单 | 黄气泡 + 分数 | 稳分粮草 |
| G | 加急单 | 橙气泡 +「急」角标 | 时限紧 |
| H | 高价单 | 深橙 + 钱袋小标 | 值得绕路 |
| S | 天价单 | 红金闪烁 + 全图播报 | 全场争夺点 |

气泡上只显示：**分数 + 档位角标**，不堆商家 Logo（合规：虚构店名）。

### 3.2 包裹表现（角色身上）

| 状态 | 表现 |
|------|------|
| 未持单 | 无袋或空箱 |
| 配送中 | 保温袋/箱轻微弹跳跟随 |
| 易碎/热饮标签（可后期） | 袋上「烫」「易碎」贴纸，仅提示无额外操作 |

**MVP：** 统一保温袋即可，用颜色区分档位（黄/橙/红袋）。

### 3.3 虚构商家与顾客（命名池示例）

**商家（取货点）：** 好饱食堂、夜半面馆、校园鸡排、写字楼咖啡、河边奶茶铺  

**顾客称呼（送达气泡）：** 宿舍 302、A座前台、夜市摊主、快递驿站姐姐  

禁止真实连锁品牌名与商标造型。

## 4. C. 主动技能道具

### 4.1 加速门 `SK_BOOST`（默认）

| 项 | 内容 |
|----|------|
| 表现 | 脚下风圈 + 残影；自身描边变亮 |
| 手感语义 | 「我要迟到了冲刺」 |
| 公平 | 仅自己，无遮挡 |

### 4.2 倒油 `SK_OIL`

| 项 | 内容 |
|----|------|
| 表现 | 前摇：地面预警圈；命中：油渍拖尾、目标车身打滑感 |
| 手感语义 | 「路滑！！」 |
| 禁忌 | 不做写实污秽特写；保持卡通油渍 |

### 4.3 假单诱饵 `SK_BAIT`

| 项 | 内容 |
|----|------|
| 表现 | 半透明「假」字气泡，3 秒后碎掉 |
| 手感语义 | 「骗你的～」 |
| 公平 | 点击无单 + 明确假标，避免纯欺诈无反馈 |

### 4.4 糊纸箱 `SK_BOX`（P1）

对方 HUD 边缘糊一层纸箱纹理 1.2s（非全黑）；需联机体验验证后再上。

### 4.5 技能获取方式（产品）

- 开局自带加速  
- 局内花金币买倒油 **或** 诱饵其一（技能槽一个互害）  
- 不做复杂背包页

## 9. 道具呈现优先级（避免花活压过玩法）

1. 订单气泡与导航目标  
2. 载具类型差异  
3. 技能预警与命中反馈  
4. 换车站  
5. 装饰与皮肤  

任何新道具若让「第一次玩的人 10 秒内不知道点啥」，砍表现或砍功能。

## 10. MVP 道具清单（制作表）

| 3 载具俯视造型 | 单车/电动/摩托 |

| 取货点/顾客点地面标识 | 蓝圈 / 紫圈 |

**明确不做进 MVP 资源表：** 迈巴赫、公路车、糊纸箱、双肩包、天气层、付费皮肤。
