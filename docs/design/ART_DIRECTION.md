# 《极速外卖》美术与视觉风格规范

> 文档类型：产品 / 美术方向（不含技术实现）  
> 版本：v1.0 · 2026-09-07  
> 状态：**风格已锁定**

---

## 1. 风格选型结论

**锁定风格：夸张都市卡通俯视角（Stylized Urban Cartoon · Top-down）**

一句话：像「会动的表情包城市」——角色 Q 一点、载具辨识度极高、场景明亮干净，不写实、不做硬核像素。

| 候选 | 结论 | 原因 |
|------|------|------|
| 写实风 | **否** | 成本高、抖音小游戏短局不吃细节；迈巴赫送奶茶会显得诡异而非好笑 |
| 硬核像素风 | **否（备选）** | 产能友好，但豪车反差、表情名场面、技能特效的「传播辨识度」弱于卡通 |
| **夸张都市卡通** | **采用** | 最贴合派对竞技 + 喜剧反差 + 短视频截图传播；MVP 可用色块+清晰剪影快速出图 |

**备选触发条件：** 若核心美术仅擅长像素、或首包/产能被严格卡死，可降级为「明亮像素卡通」（仍禁止写实）。需书面改本文件版本号。

## 2. 风格关键词（给美术的情绪板）

**要：**

- 明亮、饱和、干净  
- 略微夸张的比例（头稍大、车剪影一眼可辨）  
- 喜剧感、生活感、抖音「当下感」  
- 俯视可读：功能点颜色编码稳定  

**不要：**

- 灰暗赛博 / 写实泥土地面  
- 过度拟真光影与 PBR  
- 血腥、恶心特写  
- 复杂 UI 花纹抢内容  
- 默认「紫雾霓虹」或「奶油衬线 Terracotta」等泛 AI 模板感

## 3. 镜头与空间语言

| 项 | 规定 |
|----|------|
| 视角 | 俯视略斜 2D/2.5D（约 45° 可接受，优先纯俯视保证操作准） |
| 角色占比 | 角色直径约占屏宽 4%–6%，保证 4 人同屏不糊 |
| 信息优先级 | 订单气泡 > 玩家载具色 > 技能特效 > 场景装饰 |
| 装饰密度 | 「舞台感」而非开放世界：装饰服务于认路，不堆砌 |

## 5. 角色与载具造型原则

### 5.1 外卖员

- 统一识别物：**保温箱 / 马甲色块**（比脸更重要）  
- 四名玩家靠 **马甲色 + 号码** 区分，不靠写实五官  
- 表情可做 3–4 套：常态 / 加速得意 / 被减速懵 / 送达胜利  

### 5.2 载具（喜剧阶梯）

| 载具 | 造型关键词 | 辨识剪影 |
|------|------------|----------|
| 共享单车 | 共享蓝、车筐、略显寒酸 | 细高两轮 |
| 公路车 | 瘦长、竞速感 | 弯把剪影 |
| 电动车 | 外卖标配、稳 | 箱体+踏板 |
| 摩托车 | 张扬、排气夸张 | 低趴+盔 |
| 迈巴赫（后期） | **过度豪华、发光轮毂、不合时宜** | 超长轿车，一眼「不对劲的好笑」 |

原则：越高级越「夸张不合时宜」，而不是越来越写实贵气。

## 6. UI 视觉与场景的关系

- 局内 HUD：扁平、大字号、半透明底，不遮挡车头方向  
- 结算页：可略加强品牌橙与漫画速度线，服务「再来一局」  
- 大厅：一张主题插画街区即可，避免仪表盘式多卡片  

详细线框见 [UI_IA.md](../specs/UI_IA.md)。

## 7. 传播截图测试（美术验收用）

任意对局截图，去掉文字后仍应能读出：

1. 谁是外卖员  
2. 哪辆是「好车」  
3. 哪里在抢单/互坑  

若读不出，优先改剪影与配色，不先加细节。
