# 《极速外卖》MVP 范围锁定

> 状态：**已确认（Locked）**  
> 日期：2026-09-07  
> 依据：产品 PRD 拍板结论 — 派对轻竞技，不做外卖模拟器 / 重养成

## 1. MVP 目标

用最小可玩版本验证四段核心爽感：

1. **抢单** — 争高价值单有冲突感  
2. **送达** — 限时压力与路线选择  
3. **换车** — 局内短成长改变决策  
4. **干扰** — 可读、可反制的轻度互害  

验证通过后再扩展迈巴赫、多地图、段位匹配等。

## 2. 纳入范围（In Scope）

| 模块 | MVP 内容 |
|------|----------|
| 地图 | **1 张**：大学城街区（俯视角，对角线约 8–12 秒） |
| 载具 | **3 种**：共享单车 / 电动车 / 摩托车 |
| 订单 | 三步流程：抢单 → 取货 → 送达；同时持有 **1 单** |
| 单机 | 挑战关：目标分 + 1–2 个简单 NPC 抢单员 |
| 联机 | **好友房 2–4 人**（房主选时长 180s） |
| 技能 | **2 个互害**（倒油减速、假单诱饵）+ **1 个加速** |
| 结算 | 排名 1–4 + 激励视频「收益翻倍」入口 |
| 操作 | 虚拟摇杆 + 单一互动/技能键 |
| 引导 | 首局 15 秒内完成「抢→取→送」三步提示 |

## 3. 明确不做（Out of Scope / MVP 禁止项）

- 迈巴赫及其他超载具  
- 公路车（v1.0 再加）  
- 大世界 / 多地图轮换  
- 语音聊天、观战  
- 局外重养成、永久属性付费碾压  
- 快速匹配、段位赛季  
- 双肩包持 2 单、复杂天气事件卡池  
- 结算高光视频投稿（v1.0+）  
- 糊纸箱等强 UI 遮挡技能（联机体验验证后再评估）  

## 4. 验收门槛（通过才扩内容）

| 指标 | 门槛 |
|------|------|
| 新手首次完成一单 | ≤40s |
| 平均单局时长 | 150–210s |
| 单局人均完成单数 | 4–8 |
| 「想再来一局」点击率 | ≥45% |
| 联机「觉得被恶心」问卷占比 | ＜25% |

## 5. 签字确认

| 角色 | 结论 |
|------|------|
| 产品 | 同意锁定上述 In/Out Scope |
| 设计 | 同意以灰盒验证四段爽感为扩容前置条件 |
| 程序 | 同意技术选型：Cocos Creator 3.x + WebSocket 好友房 |

**变更规则：** 任何新增 MVP 功能须书面改本文件版本号；默认拒绝「顺手加一点」。
